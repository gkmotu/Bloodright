# Bloodright rules reference

This folder contains the official **System Reference Document 5.2.1** (SRD 5.2.1), the current Creative Commons reference for the revised 2024/2025 fifth-edition rules.

- Read the local file: `SRD_CC_v5.2.1.pdf`
- Official source and future updates: <https://www.dndbeyond.com/srd>
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/legalcode)

Bloodright uses the SRD as a mechanics reference and develops its own world, names, story, artwork, items, and creatures. Do not add scans or copies of paid D&D books to this repository.
